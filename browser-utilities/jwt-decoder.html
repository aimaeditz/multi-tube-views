Key Features & Privacy

✓ 100% Client-Side Privacy

Tokens are never transmitted over the network or logged anywhere.

✓ Human Timestamp Conversion

Converts Unix epoch claims (exp, iat, nbf, auth_time) into readable local dates.

✓ Visual Token Parts Breakdown

Color-coded Header (Red), Payload (Purple), and Signature (Cyan).

🔒 Complete Client-Side Isolation

This tool runs entirely in your local browser runtime. No logs, analytics tracking, or remote server transmissions occur.
